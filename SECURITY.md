# Segurança / Security

PT-BR: nunca publique segredos ou dados reais em Issues. Se a opção “Report a vulnerability” estiver disponível na aba Security, use o canal privado. Caso contrário, solicite um contato privado em uma Issue sem detalhes exploráveis. Use reprodução sintética e descreva impacto, versão e ambiente. A biblioteca não é certificação de segurança.

EN-US: never disclose secrets or real data in Issues. If “Report a vulnerability” is available under Security, use that private channel. Otherwise request a private contact in an Issue without exploit details. Use a synthetic reproduction and describe impact, version and environment. The library is not a security certification.
