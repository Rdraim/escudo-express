# Instruções / Instructions

- PT-BR: código público reutilizável, documentação em português brasileiro e inglês dos EUA; exemplos sintéticos, sem dados de usuários.
- EN-US: reusable public code, documentation in Brazilian Portuguese and US English; synthetic examples, no user data.
- Preserve APIs and meaningful tests. No private source export, secrets, production access or automatic dependency installation. Inspect the diff and git history before publishing.
- Keep both README languages synchronized, document limitations and run npm test where available. The skill repository uses npm test for package validation.
- Donations remain optional and unconfigured until the owner explicitly provides a public payment channel. Never infer payment details from a private source.
- UI: accessible loose window icons with tooltips; proportional fields; responsive layout; light/dark themes; keyboard, scroll and minimize/restore preserving fields.
- Changes inspired by Nexus must be generalized and reviewed; do not assume these public libraries are automatically imported into Nexus.
